# Морковки на связи — Android

Android WebView-приложение для тестового сервера `http://212.220.99.132:5761/`.

⚠️ Это тестовая HTTP-сборка. Не вводите реальные пароли и личные данные: HTTP не шифрует трафик. Для боевого использования нужен HTTPS.

## Сборка APK

Откройте вкладку **Actions → Android test APK**, найдите успешный запуск и скачайте артефакт **Morkovki-IP-Android-Debug-APK**. APK появится только после успешной сборки.

Исходная разработка получена из предоставленного архива «морковки андроид.zip». Локальный ключ подписи в репозиторий не загружается.

Если приложение сообщает об ошибке подключения, убедитесь, что сервер слушает `0.0.0.0:5761`, а брандмауэр разрешает входящие соединения. Если там API без веб-интерфейса, WebView надо перенастроить на адрес фронтенда.
