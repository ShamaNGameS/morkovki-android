# Морковки на связи — Android

Это Android-приложение открывает текущий сайт Морковок и использует вход через Google.

Android-функции: HTTPS-страницы открываются внутри приложения, кнопка «Назад» возвращает по истории; текст можно отправить в приложение через системное меню «Поделиться»; HTML5-видео поддерживает полноэкранный режим. Если поделиться текстом, когда поле сообщения не открыто, текст копируется в буфер обмена для вставки в чат.

## Сборка

Откройте эту папку в Android Studio или выполните `gradlew.bat assembleDebug` из PowerShell.

APK собирается в `app\build\outputs\apk\debug\app-debug.apk`.

Полноэкранное видео, системное меню «Поделиться» для текста и открытие HTTPS-страниц внутри приложения поддерживаются Android-оболочкой.

Локальный `signing\android-debug.keystore` используется для обновления установленной тестовой версии и намеренно не хранится в GitHub. На компьютере без этого файла Gradle использует стандартную отладочную подпись; такой APK нельзя установить поверх версии с локальным ключом.
