# Морковки на связи — Android 1.8.1

Восстановленный Android-проект со всеми исходными файлами: MainActivity.java, assets/chat.html, Gradle Wrapper, ресурсы и интеграции.

## Две сборки в GitHub Actions

- **Morkovki-IP-HTTP-Test-Debug-APK** открывает `http://212.220.99.132:5761/`. Нативный Google Sign-in и Android JS-мост отключены: HTTP не защищает токены и личные данные.
- **Morkovki-Website-HTTPS-Debug-APK** открывает `https://morkovkionline.ru/` с прежними Android-функциями и Google Credential Manager. Серверная интеграция OAuth должна быть корректно настроена.

Сохранены поддержка загрузок/вложений, системное меню «Поделиться», полноэкранное видео, разрешения для HTTPS-камеры/микрофона и исходный встроенный демонстрационный HTML-чат.

## Локальная сборка

Требуется JDK 17, Android SDK 35. Вариант сайта по умолчанию использует HTTPS.

```bash
./gradlew --no-daemon assembleDebug "-PsiteUrl=http://212.220.99.132:5761/"
./gradlew --no-daemon assembleDebug "-PsiteUrl=https://morkovkionline.ru/"
```

Каждая команда перезаписывает `app/build/outputs/apk/debug/app-debug.apk`.

**Важно:** IP-тест передаёт данные без шифрования. Не вводите настоящие пароли, токены или личные сообщения. Для рабочего приложения настройте HTTPS. WebView требует HTML-фронтенд: если порт 5761 отдаёт только JSON API, нужен другой стартовый URL или отдельный API-клиент.

**Подпись:** файл `signing/android-debug.keystore` не публикуется. APK с подписью GitHub Actions может потребовать удаления старой тестовой версии перед установкой (при удалении теряются локальные данные).

## Google-вход через аккаунт Android (1.8.2)

HTTPS-сборка теперь имеет кнопку «Войти Google» и перехватывает переходы на `accounts.google.com`, вместо открытия браузера. Android Credential Manager может показывать аккаунты, настроенные в телефоне. Кнопка вызывает нативный выбор **только если** HTTPS-сайт поддерживает `__morkovkiNativeGoogleStart()` (предпочтительно; функция получает nonce сервера и вызывает `MorkovkiAndroid.startGoogleSignIn(nonce)`) или `__morkovkiNativeGoogleComplete(idToken)` (режим совместимости; nonce передаётся событием `morkovki-native-google-start`). На сервере обязательны проверка Google ID Token (подпись, audience, expiry, nonce) и создание сессии сайта по HTTPS. Без серверной интеграции приложение сообщает об этом, но не имитирует успешный вход.

HTTP/IP-вариант **не** передаёт ID-токены и не может безопасно выполнять вход Google. Для реального входа используйте HTTPS-сборку и зарегистрируйте SHA-1 ключа подписи установленного APK как Android OAuth client в Google Cloud, с `ru.morkovki.chat` в качестве package name. `google_server_client_id` остаётся Web Client ID.


## Android 1.8.3: портретный режим и вход через почту

- Исправлены обработка системной клавиатуры (IME), высота WebView, safe areas и прокрутка к полю ввода.
- На узких телефонах WebView использует мобильный viewport; верхние кнопки не должны сжиматься/выталкиваться заголовками, в том числе в разделе друзей.
- Кнопка нативного Google-входа появляется только на странице входа, чтобы не перекрывать кнопки чата и друзей.
- Android Autofill включён для сохранённых email/паролей; сохранение HTTPS-сессионных cookie при уходе приложения в фон.
- Портретная ориентация для стандартных мобильных телефонов.

**Серверная авторизация:** Android здесь лишь сохраняет сессию и показывает форму сайта. Полноценная проверка email/пароля, сброс пароля, email verification и выдача сессии должны выполняться сервером сайта по HTTPS. Исходников сервера в этом репозитории нет: **не добавлять небезопасные обходы и фиктивные локальные аккаунты**. Нативный Google-вход также требует серверной поддержки callback/nonce. HTTP/IP-сборку не используйте для реальной авторизации.

Скриншоты до изменений показывали проблемы, но реальную проверку на устройствах с разными IME и размерами экрана ещё нужно выполнить.
