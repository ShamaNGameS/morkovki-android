# Морковки на связи — Android IP-тест

Это **облегчённая тестовая WebView-сборка** Android-приложения, сделанная для первого теста подключения к выделенному серверу. Исходный полноценный проект из архива пользователя сохраняется отдельно; данная тестовая ветка не содержит его нативных интеграций (Google Sign-in, загрузка медиа и др.).

* Адрес сервера: **http://212.220.99.132:5761/**
* Android package: `ru.morkovki.chat`
* Версия: `1.8.1-ip-test`
* Ключ подписи: собственный debug-ключ CI (локальный keystore не публикуется).

## Сборка

GitHub → **Actions** → **Android test APK** → успешный run → **Artifacts** → `Morkovki-IP-Android-Debug-APK`.

Workflow автоматически запускается после загрузки кода в main. Для локальной сборки установите JDK 17, Android SDK 35 и Gradle 8.13, затем выполните `gradle assembleDebug`.

## Безопасность

Порт 5761 использует HTTP, а значит информация передаётся **без шифрования**. Не используйте реальные пароли, токены или конфиденциальные сообщения. Для настоящей авторизации нужен HTTPS. WebView не имеет JavaScript-моста Android; камера и микрофон не интегрированы. Для основного приложения следует добавить полноценные возможности из исходного проекта после перехода на HTTPS.

Если соединение отклонено, проверьте, что сервер слушает `0.0.0.0:5761`, брандмауэр разрешает трафик, а адрес возвращает веб-страницу, а не только JSON API.
