# Морковки Онлайн — Android 1.9.1

Статус: исходный код версии 1.9.1 и CI-сборка тестового APK. Публикация рабочего Direct-IP APK зависит от настройки сервера.

## Что изменилось по сравнению с 1.9.0

- Android: `versionName 1.9.1`, `versionCode 24`.
- Добавлен вариант Direct HTTPS IPv4 APK (ручной GitHub Actions); домен не используется как резервный адрес.
- Перед Direct IP сборкой проверяется доступность реального веб-интерфейса (`/chat`), маршрута авторизации без сессии (`/api/auth/me`), HTTPS-сертификата и отсутствие редиректа на домен.
- Добавлены unit-тесты preflight и интеграция их с обычной CI-сборкой.
- Уточнено правило: сайт и Android используют существующую систему регистрации по нику и паролю, одну БД, а не отдельные APK-аккаунты.

## Важно

Основной HTTPS-домен продолжает работать в обычной сборке. Для Direct IP на Windows-сервере ещё требуется действующий публичный HTTPS по IP с доверенным IP-сертификатом, без перенаправления на домен, и проверка настоящего входа/регистрации. Проверки CI **не тестируют реальные аккаунты**. Сервер, БД и пользовательские данные автоматически не изменяются.

## APK

Обычная версия: GitHub Actions → `Android APK - Google HTTPS` → артефакт `Morkovki-Online-APK`.

Прямой IP: GitHub Actions → `Android APK - Direct HTTPS IP` → артефакт `Morkovki-Direct-IP-APK` **только после успешного IP HTTPS preflight**.

Для установки 1.9.1 поверх предыдущей версии нужен один и тот же ключ подписи APK.
